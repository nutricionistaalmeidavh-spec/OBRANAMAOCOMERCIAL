# Obra na Mão Comercial

Aplicação comercial do ecossistema **Obra na Mão**, com experiência web/PWA e desktop.

## Estrutura

```text
apps/
  web/       Cloudflare Workers + PWA
  desktop/   Electron
packages/    pacotes compartilhados
docs/        documentação
```

Consulte `apps/web/CLOUDFLARE_DEPLOY.md`, `DESKTOP_RELEASES.md` e os documentos de entrega/migração para detalhes operacionais.
